# Gamerzeta content model

All published content is written in English and stored as one Markdown file per article under its category directory.

Required frontmatter: `title`, `slug`, `category`, `game`, `author`, `date`, `dek`, `cover`, `cover_alt`, `cover_source`, `tags`, `reading_time`, `tier`, and `featured`.

Reviews additionally use `rating`, `verdict`, `pros`, and `cons`.

Image convention: `/wp-content/uploads/YYYY/MM/DD/filename.webp`. Covers must have explicit dimensions in rendered HTML, use descriptive alt text, and be optimized before publication.
